# 🗺️ 모임 이벤트 관리 웹 MVP - 개발 로드맵

소규모 모임 주최자가 이벤트 공지, 참여자 관리, 선착순 정원 관리를 효과적으로 처리할 수 있는 웹 플랫폼

## 📋 개요

본 로드맵은 **구조 우선 접근법(Structure-First Approach)**을 따릅니다:

1. **Phase 1**: 애플리케이션 골격 및 전체 페이지 구조 구축
2. **Phase 2**: 모든 UI/UX 완성 (더미 데이터 활용)
3. **Phase 3**: 데이터베이스 및 API 개발
4. **Phase 4**: 고급 기능 및 최적화

이 방식으로 빠르게 UI/UX를 테스트하고 피드백을 반영한 후 데이터베이스를 연동합니다.

### 📌 MVP 핵심 기능 매핑

| 기능 ID | 기능명 | Phase | 상세 |
|--------|--------|-------|------|
| **F001** | 이벤트 생성 | Phase 2-5 | 이벤트 생성 페이지 UI |
