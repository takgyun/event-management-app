# 모임 이벤트 관리 웹 MVP PRD

## 🎯 핵심 정보

**목적**: 소규모 모임 주최자가 이벤트 공지, 참여자 관리, 선착순 정원 관리를 효과적으로 처리할 수 있는 웹 플랫폼 제공

**사용자**: 독서, 친목, 자전거나 달리기 같은 소규모 모임(10~30명)을 주최하는 개인

---

## 🚶 사용자 여정

```
1. 비로그인 사용자
   ↓ 홈 페이지 접속

   [이벤트 조회 원함]           [회원가입/로그인 원함]
   ↓                          ↓
   이벤트 목록 페이지           로그인 페이지 → 회원가입 페이지
   ↓                          ↓
   이벤트 상세 페이지 (조회)    로그인 완료
   ↓                          ↓
   (로그인 필요) 참가 신청 버튼  대시보드 (내 이벤트/참가 이벤트)
   ↓
   로그인 페이지로 리다이렉트

2. 로그인 사용자 (참가자)
   ↓ 대시보드 진입

   [이벤트 검색]              [참여 이벤트 확인]      [내 이벤트 생성]
   ↓                        ↓                    ↓
   이벤트 목록 페이지         이벤트 상세 페이지       이벤트 생성 페이지
   ↓                        ↓                    ↓
   이벤트 상세 페이지         [참가 신청/취소]       이벤트 저장
   ↓                        ↓                    ↓
   [참가 신청] ✓ confirmed   공지사항 확인          내 이벤트 생성됨
   또는 waitlist             ↓
   ↓                        대시보드 (참가중)
   참가 상태 확인

3. 로그인 사용자 (주최자)
   ↓ 대시보드 진입

   [이벤트 생성]            [이벤트 관리]
   ↓                       ↓
   이벤트 생성 페이지        이벤트 관리 페이지
   ↓                       ├─ [참가자 명단 확인]
   ↓                       │  └─ confirmed/waitlist 탭
   이벤트 저장              ├─ [공지사항 작성]
   ↓                       └─ [이벤트 수정/취소]
   이벤트 상세 페이지        ↓
   ↓                       변경사항 저장
   참가자 관리 페이지로 이동

```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|-----------|
| **F001** | 이벤트 생성 | 제목, 날짜/시간(필수), 장소/설명(선택)을 입력하여 새로운 이벤트 생성 | 주최자가 이벤트를 만드는 핵심 기능 | 이벤트 생성 페이지 |
| **F002** | 이벤트 조회 | 전체 이벤트 목록 조회 및 이벤트 상세 정보 확인(제목, 날짜, 장소, 주최자, 참가자 수) | 사용자가 참여 가능한 이벤트를 발견하는 기본 기능 | 이벤트 목록 페이지, 이벤트 상세 페이지 |
| **F003** | 이벤트 참가 신청 | 사용자가 이벤트에 참가 신청(정원 범위 내: confirmed, 초과: waitlist) | 참여자가 이벤트에 참가하는 핵심 기능 | 이벤트 상세 페이지 |
| **F004** | 선착순 정원 관리 | 정원 초과 시 자동으로 대기자 명단으로 이동, confirmed 취소 시 waitlist 자동 승격 | 공정한 참가 기회 제공 및 정원 관리 효율화 | 이벤트 상세 페이지, 이벤트 상세 페이지 |
| **F005** | 참가 취소 | 사용자가 신청한 이벤트 참가 취소(confirmed/waitlist 모두 가능) | 사용자 변심 대응 | 이벤트 상세 페이지 |
| **F006** | 참가자 관리 | 주최자가 확정 참가자/대기자 명단 확인 및 상태 조회 | 주최자가 참가자 상황을 파악하는 기능 | 이벤트 관리 페이지 |
| **F007** | 공지사항 작성/조회 | 주최자가 참가자들에게 공지사항 전달(장소 변경, 일정 변경 등) | 효율적인 참가자 소통 수단 | 이벤트 관리 페이지, 이벤트 상세 페이지 |
| **F008** | 이벤트 수정/취소 | 주최자가 이벤트 정보 수정 또는 이벤트 취소 | 주최자의 변경사항 대응 | 이벤트 관리 페이지 |
| **F009** | 초대 링크 공유 | 이벤트 초대 링크 복사 및 다양한 방식으로 공유(클립보드 복사, Web Share API 등) | 주최자가 이벤트를 참가자에게 효과적으로 홍보할 수 있음 | 이벤트 상세 페이지, 이벤트 관리 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|-----------|
| **F010** | 기본 인증 | 회원가입(이메일, 비밀번호) / 로그인 / 로그아웃 | 사용자 식별 및 서비스 이용 권한 관리 | 로그인 페이지, 회원가입 페이지 |
| **F011** | 대시보드 | 로그인 사용자의 내 이벤트 목록 + 참가 이벤트 목록 표시 | 사용자가 관련 이벤트를 한눈에 파악 | 대시보드 페이지 |
| **F012** | 권한 검증 | 비주최자는 수정/삭제 불가, 비로그인 사용자는 참가 신청 불가 | 데이터 보안 및 서비스 무결성 | 모든 페이지 |

### 이벤트 상세 페이지

> **구현 기능:** `F002`, `F003`, `F004`, `F005`, `F009` | **메뉴 위치:** 이벤트 목록 하위

| 항목 | 내용 |
|------|------|
| **역할** | 선택한 이벤트의 전체 정보 확인 및 참가 신청, 초대 링크 공유 |
| **진입 경로** | 이벤트 목록 페이지에서 이벤트 카드 클릭 |
| **사용자 행동** | 이벤트 정보 확인(제목, 날짜, 장소, 설명, 참가자 수) → 참가 신청/취소 버튼 클릭 또는 초대 링크 복사 또는 공지사항 확인 |
| **주요 기능** | • 이벤트 정보 표시 (제목, 날짜, 시간, 장소, 설명)<br>• 참가자 수 표시 (확정 N명, 대기자 M명, 정원 P명)<br>• 주최자 정보 표시<br>• **"초대 링크 복사"** 버튼 (모든 사용자)<br>  - 클립보드에 이벤트 초대 링크 복사<br>  - 복사 성공 시 "복사됨" 피드백 표시<br>  - Web Share API 지원 시 "공유" 버튼 추가<br>• **"참가 신청"** 버튼 (로그인 필요)<br>  - 정원 미초과: confirmed 상태로 즉시 참가<br>  - 정원 초과: waitlist 상태로 추가<br>  - 이미 신청: 상태 표시 + **"참가 취소"** 버튼<br>• **"참가 취소"** 버튼 (신청 후에만 표시)<br>• 내 현재 상태 뱃지 (confirmed/waitlist/비신청)<br>• 공지사항 목록 (confirmed 참가자만 조회 가능) |
| **다음 이동** | "초대 링크 복사" 성공 → "복사됨" 상태 2초 표시 후 복원 / "참가 신청" 성공 → 상태 뱃지 업데이트, "참가 취소" 표시 / "참가 취소" 성공 → "참가 신청"으로 복구 + 대기자 자동 승격 처리 / 로그인 필요 시 → 로그인 페이지로 리다이렉트 |
