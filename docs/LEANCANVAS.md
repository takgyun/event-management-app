# 린 캔버스 (Lean Canvas)

## 모임 이벤트 관리 웹 플랫폼

---

### 1️⃣ 문제 (Problem)

- **기존의 전단지나 메신저 공지의 한계**
  - 참가자 관리가 비체계적이고 수동적
  - 선착순 정원 관리가 어려움
  - 공지사항 전파가 비효율적

- **현재 소규모 모임 주최자의 불편함**
  - 참가 신청 현황을 일일이 파악해야 함
  - 대기자 자동 관리 불가능
  - 이벤트 변경사항 공지가 산재

---

### 2️⃣ 고객 세그먼트 (Customer Segments)

- **독서 모임, 친목 모임 주최자**
  - 연령대: 20~40대
  - 규모: 10~30명 소규모 커뮤니티 운영

- **자전거/달리기 등 취미 활동 주최자**
  - 정기적 이벤트 운영 필요
  - 참가자 변동성 높음

---

### 3️⃣ 가치 제안 (Unique Value Proposition)

- **간단한 선착순 정원 관리**
  - 정원 초과 시 자동으로 대기자 명단 관리
  - 확정 참가자 취소 시 대기자 자동 승격

- **효율적인 참가자 소통**
  - 공지사항 작성/조회 기능으로 참가자와 직소통
  - 이벤트 변경사항 실시간 공유

- **스마트폰에서 직관적으로 관리**
  - 초대 링크 복사 및 공유 기능
  - 직관적인 UI로 쉬운 사용

---

### 4️⃣ 해결책 (Solution)

- **이벤트 생성 및 관리 페이지**
  - 제목, 날짜/시간, 장소, 설명, 정원 입력
  - 쉬운 이벤트 수정/취소 기능

- **자동 정원 관리 시스템**
  - 참가 신청 시 confirmed/waitlist 자동 분류
  - 취소 시 대기자 자동 승격 로직

- **공지사항 및 참가자 관리**
  - 주최자 전용 공지사항 작성 기능
  - confirmed/waitlist 참가자 목록 탭

- **초대 링크 공유 기능**
  - 클립보드 복사 및 Web Share API 지원
  - 소셜 미디어/메신저로 쉬운 공유

---

### 5️⃣ 경쟁우위 (Unfair Advantage)

- **선착순 정원 관리의 자동화**
  - 다른 모임 서비스와 달리 자동 대기자 승격 구현
  - 주최자의 수동 작업 최소화

- **20대 타겟의 미래 역량**
  - 초기 사용자는 추후 커뮤니티 리더로 성장 가능
  - 입소문을 통한 자연 확산

---

### 6️⃣ 수익 흐름 (Revenue Stream)

**MVP 단계: 무료 서비스**
- 기본 이벤트 생성/관리 기능 무제한 제공

**향후 확장 (Post-MVP)**
- 주최자 유료 기능 (고급 분석, 참가자 피드백 등)
- 광고료 (커뮤니티 추천)
- 배팅료 (참가자 쿠폰/선물 연동)

---

### 7️⃣ 비용 구조 (Cost Structure)

- **앱 개발 인건비**
  - 초기 MVP 개발 비용

- **호스팅 및 서버 비용**
  - Vercel (Next.js 배포)
  - Supabase (데이터베이스 및 인증)

- **서비스 운영비**
  - 기술 지원 및 유지보수
  - 사용자 피드백 반영 업데이트

---

### 8️⃣ 주요 지표 (Key Metrics)

- **참여도**
  - 월간 활성 사용자(MAU)
  - 이벤트 생성 수

- **주최자 만족도**
  - 주최자 사용자 수
  - 관리 기능 사용률

- **총 주문액(Traction)**
  - 월별 참가 신청 수
  - 이벤트별 평균 참가자 수
  - 대기자 자동 승격률

---

### 9️⃣ 채널 (Channels)

- **모바일 웹 (PWA 지원)**
  - 스마트폰에서 직관적 접근

- **SNS/메신저 공유**
  - 초대 링크를 통한 자연 확산
  - 커뮤니티별 입소문

- **직접 마케팅**
  - 독서 모임, 취미 커뮤니티에 직접 소개
  - 초기 사용자 확보 및 피드백 수집

---

## 📋 요약

| 항목 | 내용 |
|------|------|
| **핵심 문제** | 소규모 모임 주최자의 비효율적인 참가자 관리 |
| **타겟 고객** | 20~40대 커뮤니티 주최자 (10~30명 규모) |
| **핵심 가치** | 자동화된 선착순 정원 관리 + 효율적 참가자 소통 |
| **주요 기능** | 이벤트 생성/관리, 자동 대기자 승격, 공지사항 공유 |
| **차별성** | 대기자 자동 관리의 간편함 |
| **수익 모델** | MVP(무료) → Post-MVP(유료 기능 추가) |
| **성공 지표** | MAU, 이벤트 생성 수, 대기자 승격률 |
